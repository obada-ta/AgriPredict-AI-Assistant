## 🔥 Key Features

### 🤖 AI & Machine Learning Capabilities (8 Engines)
1. Land Suitability: Evaluates land and soil data to determine agricultural viability.
2. Crop Recommendation: Suggests optimal crops based on soil and climate conditions.
3. Soil Type Detection: Computer vision model classifying soil types from images.
4. Plant Type Recognition: AI image classification to identify plant species.
5. Plant Disease Recognition: Detects crop diseases early from leaf photos.
6. Crop Yield Prediction: Machine learning models forecasting expected crop yield.
7. Weather Risk Prediction: Analyzes weather forecasts to assess damage risks to crops.
8. Smart Agricultural Chatbot: Context-aware NLP chatbot answering complex farming queries.

### 🌐 Full-Stack & Social Platform Features
- Real-Time Messaging: Live chat and conversation features for user interaction.
- Agricultural Social Feed: Community platform supporting posts, likes, and comments for knowledge sharing.
- Robust Microservices & APIs: Node.js backend powering high-concurrency requests and data flows.

## 🛠️ Tech Stack

- Frontend / Mobile: React Native
- Backend & Real-Time: Node.js, WebSockets / Socket.io, Flask (AI microservices)
- Database: Microsoft SQL Server (MSSQL)
- AI / ML Frameworks: TensorFlow, PyTorch, Experta (Rule Engine), NLP / Computer Vision Models
